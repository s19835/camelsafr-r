# Changelog

## camelsafr 0.1.0

- Initial release.
- [`ca_attrs()`](https://s19835.github.io/camelsafr-r/reference/ca_attrs.md)
  — static basin attributes for L1–L4.
- [`ca_basins()`](https://s19835.github.io/camelsafr-r/reference/ca_basins.md)
  — basin metadata (id, lat, lng, country).
- [`ca_timeseries()`](https://s19835.github.io/camelsafr-r/reference/ca_timeseries.md)
  — annual/monthly/daily climate timeseries with optional basin and
  variable filtering.
- [`ca_info()`](https://s19835.github.io/camelsafr-r/reference/ca_info.md)
  — print dataset summary.
- [`ca_clear_cache()`](https://s19835.github.io/camelsafr-r/reference/ca_clear_cache.md)
  — remove locally cached Parquet files.
