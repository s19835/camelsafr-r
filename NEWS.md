# camelsafr 0.1.0

* Initial release.
* `ca_attrs()` — static basin attributes for L1–L4.
* `ca_basins()` — basin metadata (id, lat, lng, country).
* `ca_timeseries()` — annual/monthly/daily climate timeseries with optional basin and variable filtering.
* `ca_info()` — print dataset summary.
* `ca_clear_cache()` — remove locally cached Parquet files.
